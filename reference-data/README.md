## 使用方式

这些文件是仓库中的源资料，不会因为放入本目录就自动写入知识库。启动应用后，在“资料管理”页面选择 documents/ 下的文件并上传；可以一次选择多个文件，系统会在当前文件完成解析、切块和向量化后，再处理下一个文件。

待资料状态变为“成功”后，才会进入问答、评测和检索实验。

## 维护约定

- 只提交已获授权或可公开使用的资料，不要放入密钥、个人隐私或运行时数据库文件。
- 修改资料时保留清晰的文件名，并在提交说明中记录来源、发布日期或版本变化。
- data/、uploads/ 和 FAISS 索引属于运行时数据，不放在本目录中。
